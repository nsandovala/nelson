# Nelson

Simple Flask application demonstrating how to interact with OpenAI's API
using the latest `openai` Python client.

## Requisitos

- Python 3.10+
- Dependencias listadas en `requirements.txt`

Instala las dependencias ejecutando:

```bash
pip install -r requirements.txt
```

Asegúrate de definir la variable de entorno `OPENAI_API_KEY` con tu clave de
acceso.

## Uso

```bash
python app.py
```

Abre tu navegador en `http://localhost:5000` y consulta a HEO, un asistente
médico empático y preciso.
